# NSE F&O Dashboard

A simple, self-contained dashboard showing all NSE F&O stocks with:

- Last price (₹)
- Market cap (₹ crores)
- 1-day, 1-week, 1-month, 1-year returns
- Distance from 52-week high

Sortable by any column, filterable by symbol. Default sort: 1-day return descending.

A GitHub Actions workflow re-fetches the data every weekday after Indian market close, commits the updated `snapshot.json`, and the dashboard auto-shows the fresh numbers.

## Live demo

Once you enable GitHub Pages (see Setup below), the dashboard will be live at:

```
https://<your-username>.github.io/<repo-name>/
```

## How it works

| File | Purpose |
| --- | --- |
| `index.html` | The dashboard. Fetches `snapshot.json` on load. |
| `snapshot.json` | Latest snapshot of all F&O tickers. Re-generated by the fetch script. |
| `scripts/fno_tickers.py` | The list of NSE F&O ticker symbols. |
| `scripts/fetch_fno_snapshot.py` | Pulls data from Yahoo Finance via `yfinance` and writes `snapshot.json`. |
| `.github/workflows/refresh.yml` | Runs the fetcher on a schedule and commits the updated snapshot. |
| `requirements.txt` | Python dependencies. |

## Setup

After pushing this repo to GitHub:

1. **Enable GitHub Pages**

   Settings → Pages → Source: **Deploy from a branch** → Branch: `main` / `(root)` → Save.

   Within a minute or two, the dashboard will be live at `https://<user>.github.io/<repo>/`.

2. **Allow Actions to push to the repo**

   Settings → Actions → General → Workflow permissions: **Read and write permissions** → Save.

   This lets the scheduled workflow commit the refreshed `snapshot.json` back to the repo.

3. **(Optional) Trigger a manual refresh**

   Actions tab → "Refresh F&O snapshot" workflow → Run workflow.

## Run the fetcher locally

```bash
pip install -r requirements.txt
python scripts/fetch_fno_snapshot.py
```

This regenerates `snapshot.json` in the repo root. Then open `index.html` in a browser (or `python -m http.server` and visit `http://localhost:8000`) to view the dashboard.

## Editing the ticker list

Add or remove symbols in `scripts/fno_tickers.py`. Use NSE symbols without the `.NS` suffix — the fetcher appends it.

## Caveats

- Data comes from Yahoo Finance via the unofficial `yfinance` library. It can lag, miss tickers, or be wrong; always cross-check before trading.
- A handful of symbols may show as missing if Yahoo has renamed or delisted them (e.g. corporate actions). Update `fno_tickers.py` accordingly.
- "1-week" / "1-month" / "1-year" returns are computed from the closest trading day at or before that calendar offset.
- 52-week high is computed from the last ~252 trading days of close prices.
